# Historical circuit SVG references

Source: https://github.com/MisterSix2295/f1-circuits-svg . Downloaded 11 October 2026. Copyright ROY Jules, MIT licence retained in LICENSE. The 157 white-outline SVG layouts and circuits.json were downloaded unchanged.

These are illustrative, season-associated diagrams, not official surveyed geometry or calibrated race-event coordinates. Layout selection uses the source's explicit season ranges and a coordinate/name match against Jolpica. The selected SVG and its hash are recorded in each race manifest. No event-location markers are derived from these images.

Documented source correction: Aintree's range mistakenly lists 1995 instead of 1955. The local selector permits its sole layout in 1955, consistent with the historical race calendar; the source JSON remains unchanged.
